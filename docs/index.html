BandoPM — Physical Modeling Synthesizer

L'Atelier du Bandonéon Libre

BandoPM is a project from L'Atelier du Bandonéon Libre, built for the open-source Bandolibre MIDI bandoneon controller and playable directly in the browser via WebMIDI, multi-touch, or computer keyboard.

Real-Time Physical Modeling

Rather than playing back static audio samples, BandoPM synthesizes sound from first-principles acoustics in real time using Rust and WebAssembly (AudioWorklet): it solves the nonlinear fluid-structure interaction of blown-closed cantilever free reeds driven by Bernoulli orifice airflow, coupled 8′ + 4′ octave reed pairs sharing individual wooden celda cavities, leather pallet (zapatilla) transients, and the distinct acoustic resonances of the Left (Bajos) and Right (Cantabile) wooden boxes.
